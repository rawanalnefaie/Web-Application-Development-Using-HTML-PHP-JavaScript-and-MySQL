# Simple Web Application

## About the Project

This project is a simple web page connected to a MySQL database using PHP. The page allows the user to enter a name and age, save the data, and display it in a table.

A Toggle button was also added to change the user's status from 0 to 1 or from 1 to 0 without refreshing the page.

## Technologies Used

- HTML
- JavaScript
- PHP
- MySQL

## Database

The `users` table contains:

- `id`
- `name`
- `age`
- `status`

Sample data used:
- John, 25, 0
- Sarah, 30, 1
- Michelle, 22, 0

## Files

- `index.php` – Main page
- `insert.php` – Inserts new data
- `toggle.php` – Changes the status
- `db.php` – Connects to the database
